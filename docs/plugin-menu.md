# The plugin menu

These are under **Plugins → Water Leak Monitor**.

| Menu item | What it does |
|---|---|
| **Send Test Alert (verify Pushover + email)** | Sends a Pushover message and an email just like a real leak alert, with **(TEST)** after the sensor's name, so you can check both reach you. The Event Log says whether each was handed over to Email+ and the Pushover plugin, or says the test failed on both. Whether it actually arrived, your phone and inbox will tell you. |
| **Toggle Timestamps in Log (on/off)** | The plugin's lines in the Event Log start with the time to the thousandth of a second, which helps when lining events up. This turns that on or off. It starts on, and stays as you leave it. |
| **Show Plugin Info** | Writes the plugin's version and details of your Mac and Indigo to the log, together with the sensor being watched, the alert email address, the repeat-alert setting and whether timestamps are on. It is useful to include if you ask for help on the Indigo forum. |
